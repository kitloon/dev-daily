# Dev Daily

A Chinese 60-day full-stack learning website with 180 lessons, 60 interactive diagrams and 60 browser-based teaching labs.

- Frontend, backend and database concepts every day.
- Complete a day’s three lessons, then resume the next day after the Malaysia calendar date changes.
- Unfinished days stay in place.
- Bookmarks and progress are stored only in the current browser; devices do not sync automatically.
- Interactive labs are deterministic local simulations, not real database, cloud or AI provider calls.

This is a buildless static website. GitHub Pages publishes the repository root from `main`. No API keys, external fonts, package installation or paid model calls are required to read the lessons.

All course content is educational. Code snippets include their own context and official references; use a separate practice environment for real integration work.
